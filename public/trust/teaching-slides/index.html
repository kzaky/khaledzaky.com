01 · Watch it build  ·  06 / 29

I built this agent with Claude Code.

Claude in a loop, two tools and one contract. About 40 lines of Python.

Tonight it replays a run I set up, so it fails the same way every time. The check you'll watch me build runs for real.

# freshcart_agent/agent.py · the loop, simplified (about 40 lines in full)

system = open("prompts/system.md").read()   # the contract: no source, no claim
tools  = [read_feedback, web_search]        # read the file, search the web

while True:
    reply = claude.messages.create(system=system, tools=tools, messages=msgs)
    if reply.stop_reason != "tool_use":
        break                               # Claude says the brief is done
    for call in tool_calls(reply):
        msgs.append(run(call))              # run the tool, hand back the result

brief = json.loads(reply.text)              # problem, evidence, options, ask

04 · Evals  ·  20 / 29

Four ways a brief goes wrong

  • Fabrication: a fact with no source at all
  • Drift: a real source, bent to a number it never said (tonight's 62%)
  • Omission: the counter-evidence quietly goes missing
  • Silent regression: a model update breaks what works today
21
04 · Evals  ·  21 / 29

Let a model judge, carefully

  • It prefers longer answers
  • It likes its own phrasing best
  • It can make the same mistake the writer made
  • Use it to rank and triage, and keep the gate itself in code

What even a perfect gate misses

  • A real source bent to the wrong conclusion
  • Counter-evidence nobody cited
  • Bad reasoning built on sound facts
  • So it takes a suite, and a human still signs

04 · Evals  ·  23 / 29

Four ways to check an answer

Match the method to the question. The full map is at khaledzaky.com/trust/evals.

Code
Exact, cheap and impossible to argue with. It can't judge tone.
Reference answer
A clear signal when a known-good answer exists. Useless when one doesn't.
Model as judge
Handles nuance at scale. Comes with biases you have to design around.
Human review
The ground truth. Too slow for every run, so use it to calibrate the others.

Four questions before AI output reaches a real decision

  • Can every fact name its source?
  • Does something check that source automatically, or only a human on a good day?
  • When the check fails, does it block the document, or warn and get ignored?
  • Could you show someone the receipt six months from now?
